# 진사이트 AEO(AI 답변 인용) 측정 파일럿

- 작성일: 2026-10-27
- 상태: **설계 단계 (10/31까지 확정 예정)** — 확정 후에는 판정 기준·프롬프트 패널을 바꾸지 않는다.
- 파일럿 대상: 나리보(NARRIVO) — https://www.zinsight.co.kr/insight-radar/narrivo
- 측정 담당: **미정 (TBD)**
- 사례 공개: **나리보 동의 미확인** — 확인 전까지 결과는 내부용으로만 사용하고, 영업 자료에는 실명·화면을 쓰지 않는다.

## 1. 목적

진사이트 게재가 고객사의 AI 답변 내 **인용·언급·추천**을 높이는지 관측한다.
GA4/Search Console 지표만으로는 영업 근거가 약한 부분을 보완하기 위한 것이며,
결과는 "관측된 변화"로 서술하고 인과를 단정하지 않는다.

## 2. 대상과 대조군

| 구분 | 대상 | 비고 |
|---|---|---|
| 파일럿 | 나리보 (자체 도메인: `narrivo.io`, `company.narrivo.io`, `biz.narrivo.io`) | 진사이트 프로필·기사 게재 |
| 대조군 1~2곳 | **미정** — 아래 선정 기준으로 10/31까지 확정 | 진사이트에 게재하지 않은 동종 서비스 |

대조군 선정 기준:
- 같은 카테고리(AI 커리어/이력서 분석, 또는 중소기업용 AI 채용 검토)일 것
- 규모·인지도가 나리보와 비슷할 것 (초기 스타트업, 대형 채용 플랫폼 제외)
- 진사이트에 게재되지 않았고, 파일럿 기간 중 게재 계획이 없을 것
- 자체 웹사이트가 있을 것 (자체 사이트 인용을 셀 수 있어야 함)

선정 절차(제안): 10/29~10/30에 카테고리 프롬프트를 엔진별 1회씩 시험 실행(기록은 하되 기준선에 포함하지 않음)하고,
답변에 등장하는 소형 동종 서비스 중 위 기준을 만족하는 곳을 고른다.

카테고리 프롬프트(C01~C15)는 나리보와 대조군에 공통으로 쓴다. 한 번 실행한 답변을 대상별로 각각 판정하므로 실행 횟수는 늘지 않는다.
대조군용 브랜드 프롬프트는 나리보 브랜드 프롬프트(B01~B05)와 같은 문형으로 대조군 확정 시 함께 고정한다.

엔진 설정(로그인 여부, 요금제, 모델, 검색 사용 여부, 지역/언어)은 첫 측정 때 `measurement-log.csv`의 `엔진_설정`에 적고, 기간 내내 동일하게 유지한다.
엔진 측의 모델 업데이트 등 통제할 수 없는 변경을 알게 되면 `change-log.md`에 적는다.

## 4. 프롬프트 패널

- 20개 고정: 브랜드 5(`B01~B05`) + 카테고리(구매 의도) 15(`C01~C15`), 한국어. 파일: `prompt-panel.csv`
- 10/31 확정 이후 문구 변경 금지 (띄어쓰기·문장부호 포함). 오탈자를 발견해도 고치지 않고 비고에만 기록한다.
- 브랜드와 카테고리 결과는 **합산하지 않고 따로 보고**한다.

## 5. 실행 규칙

- 프롬프트 × 엔진당 **5회 반복**
- 매 회 **새 세션**(새 대화, 이전 대화 기록·메모리·개인화 끔), 동일 계정·동일 설정
- **같은 요일·같은 시간대**에 실행 (예: 화요일 10:00~13:00 KST — 확정 시 기입)
- 1회 측정 = 20 프롬프트 × 3 엔진 × 5회 = **300회 응답**

> ⚠ 작업량 주의: 300회 응답을 수동으로 실행·판정하면 주 2~3시간 안에 끝나기 어렵다(응답 1건당 1분만 잡아도 5시간).
> 확정 전에 아래 중 하나를 정해야 한다. (6절 판정 기준은 어느 쪽이든 그대로 적용 가능)
> - (a) 주 1회 측정 + 담당자 시간 확대
> - (b) 반복 횟수 조정(예: 카테고리 5회, 브랜드 3회) — 사전에 확정하고 이후 변경 금지
> - (c) 실행은 스크립트/API로 자동화하고 판정만 수동 — 단, API 응답은 소비자 앱 화면과 다를 수 있음

## 6. 지표와 판정 기준 (결과를 보기 전에 확정)

### 6.1 응답 단위 판정

각 응답에서 대상(나리보, 대조군)별로 판정한다.

| 항목 | 정의 |
|---|---|
| 진사이트 인용 | 답변의 출처/각주/링크에 `zinsight.co.kr` URL이 있음 (나리보 관련 페이지에 한함) |
| 자체 사이트 인용 | 답변의 출처/각주/링크에 대상의 자체 도메인이 있음 |
| 인용(합계) | 진사이트 인용 또는 자체 사이트 인용 중 하나 이상 |
| 언급 | 답변 본문에 대상 이름(별칭 포함: 나리보, NARRIVO)이 나옴 |
| 추천 | 질문에 대한 선택지·추천 목록에 대상이 포함되거나, 사용을 권하는 문장이 있음 |
| 정확성 | 대상 설명이 사실과 맞는지: 정확 / 부분 오류 / 오류 / 해당없음(언급 없음) |

정확성 판정용 기준 사실(2026-10-27 진사이트 프로필 기준): AI 커리어 분석 서비스 'NARRIVO' 운영, 이력서를 시간축 타임라인으로 분석,
2025-08 의왕시 법인 설립, 대표 황병엽, 구직자용 커리어 분석 리포트 + 기업용 NARRIVO for Business.

### 6.2 집계 지표

- **1차 지표(판정용): 카테고리 질문의 인용률(합계)**
  = 카테고리 응답 중 "인용(합계)=Y"인 응답 수 ÷ 카테고리 응답 수, 측정 회차별로 3개 엔진을 합쳐 계산 (회차당 분모 15×3×5=225)
- 보조 지표(판정에 쓰지 않고 함께 보고): 엔진별 인용률, 진사이트 인용률과 자체 사이트 인용률 각각, 언급률, 추천률, 정확성 분포, 브랜드 질문 지표 전체, 구글/네이버 수동 확인 결과
- 대조군은 진사이트 인용이 구조적으로 0이므로, 대조군의 인용률은 자체 사이트 인용률과 같다. 비교 시 나리보의 자체 사이트 인용률도 함께 본다.

### 6.3 판정 규칙

- 기준선 평균 `B` = 기준선 기간 모든 회차의 1차 지표 평균
- 기준선 변동 폭 `W` = 기준선 회차들의 1차 지표 (최댓값 − 최솟값). 단, `W`가 3%p보다 작으면 `W = 3%p`로 본다 (0% 근처에서 변동 폭이 0이 되어 판정이 무의미해지는 것을 막기 위한 하한)
- 사후 평균 `A` = **사후 3~4주차** 회차들의 1차 지표 평균 (1~2주차는 크롤링·색인 지연 구간으로 보고 판정에서 제외, 보고에는 포함)
- 변화량 `Δ = A − B`

**"변화 관측" 판정은 아래 두 조건을 모두 만족할 때만 내린다.**
1. 나리보: `Δ_나리보 ≥ 2 × W_나리보`
2. 대조군(확정된 모든 대조군 각각): `Δ_대조군 < 2 × W_대조군`

그 외에는 "판정 기준을 충족하는 변화가 관측되지 않음"으로 보고한다.
조건 1만 충족하고 조건 2를 충족하지 못하면 "엔진 쪽 전반적 변화 가능성"으로 보고한다.

- 이 기준은 10/31 확정 후 **사후에 변경하지 않는다.**
- 결과는 "관측된 변화"로 서술한다. 표본이 작고(대상 1곳) 엔진 변화를 통제할 수 없으므로 인과를 단정하지 않는다.

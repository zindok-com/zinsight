# Zinsight (진사이트) UI/UX 설계 전략

## 1. 디자인 컨셉
- **브랜드 퍼스널리티**: 전문성, 신뢰도, 데이터 기반 통찰력
- **비주얼 스타일**: 하이브리드 미디어 + 인텔리전스 허브 (Bloomberg, NYT 스타일 결합)
- **핵심 요소**: 고밀도 정보 레이아웃, 정밀한 타이포그래피, 선과 여백을 활용한 전문성 강조

## 2. 컬러 팔레트
- **Primary**: Deep Navy (#001F3F) - 신뢰와 권위
- **Point**: Electric Blue (#0074D9) - 현대적 감각과 데이터 강조
- **Background**: White (#FFFFFF) & Light Grey (#F8F9FA) - 가독성 확보
- **Text**: Dark Grey (#1A1A1A) - 전문적인 텍스트 렌더링

## 3. 화면별 설계 포인트
### 3.1 메인 페이지 (Home)
- 미니멀한 히어로 섹션과 강력한 통합 검색바 배치.
- Insight Radar와 매거진의 주요 콘텐츠를 카드 및 리스트 형태로 미리보기.

### 3.2 Insight Radar (List)
- 전문 리서치 리포트 스타일의 고밀도 테이블/리스트 UI.
- 다중 필터 시스템 (상단 탭 + 사이드 필터)으로 데이터 접근성 극대화.

### 3.3 Organization Analysis (Detail)
- AI 기반 '섭외 원 포인트'와 비즈니스 가치 시뮬레이션 섹션 강조.
- 뉴스를 활용한 시각적 활동 타임라인 구현.

### 3.4 Zinsight 매거진
- 텍스트 가독성 중심의 저널리즘 레이아웃.
- 고품격 타이포그래피와 여백을 활용한 깊이 있는 콘텐츠 전달.
